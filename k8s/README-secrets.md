# Secrets and External Secrets Guide

## Scope
This project uses AWS Secrets Manager + External Secrets Operator (ESO) to
produce Kubernetes Secrets for API and worker pods.

Namespaces:
- app-dev
- app-prod

## Naming Rules
AWS Secrets Manager (one per env, all keys in one secret):
- app-dev-secrets
- app-prod-secrets

Kubernetes Secrets (generated by ESO):
- API: api-dev-secrets, api-prod-secrets
- Worker (shared across worker-menu_assistant/journal/review): worker-secrets

## Helm/ArgoCD Alignment
API chart fullname:
- Uses release name in fullname (api.fullname)
- ArgoCD app names are api-dev / api-prod
=> Secret name must be api-dev-secrets / api-prod-secrets

Worker chart fullname:
- Includes release name by default (worker.fullname)
=> Resource names are per-release; Secret is shared via secretRefName=worker-secrets

ArgoCD apps (namespaces/values):
- app-dev: api-dev, frontend-dev, platform-dev, redis-dev, worker-menu-assistant-dev, worker-journal-dev, worker-review-dev
- app-prod: api-prod, frontend-prod, platform-prod, redis-prod, worker-menu-assistant-prod, worker-journal-prod, worker-review-prod
- worker menu assistant values: k8s/env/dev/worker-menu-assistant-values.yaml, k8s/env/prod/worker-menu-assistant-values.yaml

## Secret vs ConfigMap Split
Secret (ESO-managed):
- DB_PASSWORD
- JWT_SECRET_KEY
- GEMINI_API_KEY
- NAVER_CLIENT_SECRET
- NAVER_CLIENT_ID

ConfigMap (non-secret):
- REDIS_URL
- QUEUE_NAME, QUEUE_PROCESSING_NAME
- S3_BUCKET, S3_PREFIX
- LOG_LEVEL, APP_ENV, etc.

## Values/Charts Settings
Disable in-chart Secret creation:
- k8s/charts/api/values.yaml: secret.enabled = false
- k8s/charts/worker/values.yaml: secrets.enabled = false

Secret injection (envFrom secretRef):
- API: envFrom secretRef -> api-<env>-secrets
- Worker: envFrom secretRef -> worker-secrets

## External Secrets Manifests
Location:
- k8s/external-secrets/app-dev/
- k8s/external-secrets/app-prod/

Files:
- secretstore.yaml
- externalsecret-api.yaml
- externalsecret-worker.yaml

## Checklist
1) AWS Secrets Manager
   - app-dev-secrets/app-prod-secrets exist
   - keys: DB_PASSWORD, JWT_SECRET_KEY, GEMINI_API_KEY
2) ESO manifests applied in each namespace
3) api-* and worker-secrets created by ESO
4) ArgoCD sync api/worker apps
5) Pods read secret envs successfully

## Pre/Post Deployment Checklist
Pre:
- ExternalSecret target names match Helm fullnames
- in-chart Secret creation disabled

Post:
- K8s Secrets exist in app-dev/app-prod
- Pods show secret envs from ESO
- API/worker pods can connect to DB and Redis
